트립마킹 이용약관

트립마킹은 해외여행자의 소지품 안전과 스캠 대응을 돕는 정보 서비스입니다. 사이트의 정보는 참고용이며, 실제 신고와 법적 절차는 현지 경찰, 카드사, 보험사, 대사관 또는 영사관의 안내를 따라야 합니다.

이용자의 책임

사용자는 트립마킹의 정보를 불법 행위, 보복, 특정 개인 추적, 특정 집단 비난에 이용해서는 안 됩니다. 현장 상황은 도시와 시간, 동행자, 혼잡도에 따라 달라질 수 있으므로 공식 안내를 함께 확인해야 합니다.

수정 제안

콘텐츠 오류와 출처 문제는 공개 GitHub Issues에서 수정 제안으로 남길 수 있습니다. 게시물은 인터넷에 공개되므로 실명, 연락처, 얼굴 사진, 여권·카드·계정 정보, 숙소나 실시간 위치, 특정 개인을 식별할 수 있는 내용을 포함해서는 안 됩니다. GitHub 이용에는 GitHub의 약관과 정책이 적용됩니다.

콘텐츠의 한계

트립마킹은 모든 피해 가능성을 예측하거나 보장하지 않습니다. 정보는 예방과 대응 순서를 돕기 위한 것이며, 응급 상황에서는 현지 긴급번호와 공식 기관의 안내가 우선입니다.

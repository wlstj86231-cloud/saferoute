시행일 및 최종 갱신일: 2026년 8월 14일

트립마킹은 회원가입을 요구하지 않으며, 트립마킹 운영 서버에 사용자의 이름, 연락처, 현재 위치, 사고 메모 또는 이용 기록을 수집·저장하지 않습니다.

위치 정보

현재 위치 기능은 사용자가 브라우저 권한을 허용한 경우에만 작동합니다. 위치는 지도 표시와 화면 내 거리 정렬에만 사용되며 트립마킹 서버로 전송하거나 저장하지 않습니다. 위치 권한을 허용하지 않아도 도시 선택, 검색, 체크리스트와 가이드를 사용할 수 있습니다.

브라우저에 저장되는 항목

저장한 장소, 최근에 보거나 확인한 장소, 체크리스트와 상황 연습 상태, 언어 설정, 사용자가 직접 작성한 사고 메모, 화면에서 작성 중인 로컬 초안과 임의 식별값은 브라우저의 로컬 저장소에만 남을 수 있습니다. 이 정보는 같은 브라우저에서 기능 상태를 복원하기 위한 것이며 다른 기기와 동기화되지 않습니다.

브라우저 설정에서 tripmarking.com의 사이트 데이터를 삭제하면 로컬 저장 항목을 한꺼번에 지울 수 있습니다. 저장한 장소나 사고 메모처럼 화면에 삭제 기능이 있는 항목은 해당 기능으로 개별 삭제할 수도 있습니다. 브라우저 데이터 삭제 후에는 트립마킹이 복구할 서버 사본이 없습니다.

Google 광고

일부 페이지에는 Google 광고가 표시될 수 있습니다. Google과 광고 파트너는 광고 제공, 게재 빈도 관리, 측정 또는 맞춤설정을 위해 쿠키, IP 주소, 브라우저·기기 식별자와 유사 기술을 사용할 수 있습니다. 이러한 처리는 Google의 정책과 사용자의 광고 및 브라우저 설정에 따르며, 트립마킹의 로컬 저장 항목과는 별개입니다.

외부 링크와 문의

공식 출처, GitHub Issues 등 외부 사이트를 열면 해당 운영자의 개인정보 처리방침과 약관이 적용됩니다. 트립마킹은 외부 사이트가 수집하는 정보를 통제하지 않습니다.

수정 및 개인정보 관련 문의 채널은 GitHub Issues입니다. Issues의 제목과 본문은 공개되므로 실명, 연락처, 여권·카드·계정 정보, 숙소나 실시간 위치 등 개인정보와 민감정보를 입력하지 마세요.

변경 안내

회원 기능, 서버 저장 또는 새로운 외부 서비스가 추가되는 등 개인정보 처리 방식이 바뀌면 시행 전에 이 페이지의 내용과 갱신일을 수정합니다.

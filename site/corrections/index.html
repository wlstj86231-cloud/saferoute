오류를 알리는 방법

문의에 안내한 고객센터 전화(010-2846-2011), 이메일(consultingjinjeong@gmail.com), 카카오톡 오픈채팅, 공개 GitHub Issues 중 편한 곳으로 알려 주세요. 문제가 있는 페이지 주소와 문장, 확인할 수 있는 공식 출처를 함께 보내 주시면 빨리 확인할 수 있습니다. 계산 오류라면 넣은 값과 나온 결과, 기대한 결과를 적어 주세요.

고치는 순서

  1. 원문 대조 — 제보받은 문장을 국가법령정보센터 조문이나 공공기관 원문과 다시 맞춰 봅니다.
  2. 수정 또는 삭제 — 사실과 다르면 문장을 고치고, 원문이 사라졌거나 확인할 수 없게 된 문장은 내립니다. 도구 계산 오류는 같은 입력으로 다시 확인한 뒤 고칩니다.
  3. 날짜 갱신 — 원문을 다시 대조한 페이지는 최종 확인일을 바꿉니다. 게시일은 바꾸지 않습니다.
  4. 기록 — 뜻이 바뀌는 수정은 아래 수정 기록에 날짜와 함께 남깁니다. 오탈자처럼 뜻이 바뀌지 않는 수정은 따로 적지 않을 수 있습니다.
  5. 답변 — 연락처를 남긴 제보자에게는 영업일 기준으로 확인한 뒤 결과를 알립니다.

법령 개정처럼 출처 쪽이 바뀐 경우에도 같은 순서로 고칩니다. 수정 내용이 운송 계약이나 보상 결과를 보장하지는 않습니다. 개별 사안은 이용약관과 면책에 적은 기관과 당사자에게 확인하세요.

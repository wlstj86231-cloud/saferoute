문의

트립마킹의 장소 설명, 안전 문구, 출처 표기, 개인정보 처리에 관한 문의와 수정 제안은 GitHub Issues에서 접수합니다. 수정 제안에는 해당 페이지 주소, 문제가 되는 문장, 확인 가능한 공식 출처를 함께 적어 주세요.

공개 문의 시 주의사항

GitHub Issues에 작성한 제목과 본문은 인터넷에 공개됩니다. 실명, 이메일 주소, 전화번호, 여권·카드·계정 정보, 숙소나 실시간 위치, 피해자를 식별할 수 있는 내용은 입력하지 마세요. 개인정보 처리에 관한 문의도 공개 가능한 내용만 작성하고 제목 앞에 [개인정보]를 표시해 주세요.

GitHub 계정과 Issues의 이용에는 GitHub의 약관과 개인정보 처리방침이 적용됩니다. 현재 트립마킹은 이메일 문의나 비공개 문의 양식을 운영하지 않습니다.

정정 대상

사실과 다른 내용, 출처와 맞지 않는 설명, 오래된 정보, 과장된 표현, 특정 국적·외모·집단을 범죄와 연결하는 문장은 수정 대상입니다. 트립마킹은 도시 전체를 위험하다고 단정하지 않고, 여행자가 확인할 행동과 장소 맥락을 정리하는 쪽을 우선합니다.

응급 상황 안내

이 사이트는 응급 신고 창구가 아닙니다. 피해가 발생한 경우 현지 긴급번호, 경찰, 카드사, 대사관 또는 영사관에 먼저 연락해야 합니다. 트립마킹의 대처 순서는 사용자가 당황하지 않도록 돕는 참고 자료이며, 실제 신고와 법적 절차는 현지 기관의 안내를 따라야 합니다.

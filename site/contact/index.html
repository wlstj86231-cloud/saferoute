문의와 정정 요청

도구의 계산이 이상하거나, 법령 인용이 원문과 다르거나, 링크가 끊어졌다면 알려 주세요. 문의와 수정 제안은 GitHub Issues에서 받습니다.

이렇게 적어 주시면 빨리 고칠 수 있습니다

  • 문제가 있는 페이지 주소
  • 계산 오류라면: 넣은 값과 나온 결과, 기대한 결과
  • 내용 오류라면: 해당 문장과 확인할 수 있는 공식 출처(국가법령정보센터 조문 등)

공개 게시판이라는 점에 주의하세요

GitHub Issues에 쓴 제목과 본문은 인터넷에 공개됩니다. 이름, 전화번호, 상세 주소, 차량번호, 계좌번호, 견적서 사진처럼 본인이나 업체를 알아볼 수 있는 내용은 올리지 마세요. 개인정보 처리에 관한 문의도 공개해도 되는 내용만 적고 제목 앞에 [개인정보]를 붙여 주세요. 현재 이메일이나 비공개 문의 양식은 운영하지 않습니다. GitHub 이용에는 GitHub의 약관과 개인정보 처리방침이 적용됩니다.

운송 계약이나 사고 상담 창구가 아닙니다

이 사이트는 견적이나 계약에 관여하지 않으므로 운송 일정, 요금, 파손 문제는 해당 운송업체와 직접 확인해야 합니다. 운송사업자의 적재물 사고 손해배상에 관해서는 화주가 요청하면 국토교통부장관이 분쟁을 조정할 수 있다는 규정이 있습니다(화물자동차 운수사업법 제7조). 처리 순서는 운송 안전 점검표에 정리했습니다.
